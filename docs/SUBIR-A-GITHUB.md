# Cómo subir la entrega final

El proyecto completo está listo dentro de este ZIP. No se pudo guardar directamente en GitHub porque la integración rechazó la escritura con el mensaje `Resource not accessible by integration` (HTTP 403). No se modificó el repositorio.

## Desde la página de GitHub

1. Descomprimir el ZIP en una carpeta nueva. Dentro deben estar `index.html`, `assets/`, `css/`, `js/`, `data/` y `docs/`.
2. Entrar a https://github.com/fedesan2002/Comiqueria-central-9 y seleccionar la rama `main`.
3. Eliminar el `README.md` viejo de la raíz: abrirlo, elegir **Delete file** desde su menú y confirmar el cambio. El README actualizado está en `docs/README.md`, porque la consigna pide que solo quede `index.html` suelto en la raíz.
4. Usar **Add file → Upload files**. Arrastrar `index.html` y las cinco carpetas del proyecto descomprimido. Subir el contenido del ZIP, no el ZIP ni una carpeta que los envuelva.
5. Escribir un mensaje como `Completar entrega final de JavaScript` y confirmar con **Commit changes**.
6. Verificar que se reemplazaron `index.html`, `css/styles.css`, `js/catalogo.js` y `js/main.js`, y que se agregaron `data/catalogo.json`, `js/vendor/sweetalert2.all.min.js` y los documentos de `docs/`.
7. Probar con Live Server siguiendo `docs/README.md`. El repositorio ya era público cuando se realizó la revisión; comprobar que siga mostrando la etiqueta **Public** antes de entregar.

No subir archivos de navegador, capturas ni scripts de pruebas. Ya se excluyeron del ZIP.

## URL para la entrega

Después de subir los archivos actualizados, compartir:

https://github.com/fedesan2002/Comiqueria-central-9

Si preferís crear un repositorio nuevo para la entrega final, podés subir exactamente estos mismos archivos, marcarlo como público y entregar la URL de ese repositorio.
